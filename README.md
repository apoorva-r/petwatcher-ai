# PetWatch AI

A Databricks + Agentic AI portfolio project for neighbourhood missing/found pets.

## Current milestone
Milestone 1: Databricks Asset Bundle foundation.

The repository is intentionally small at this stage. We will progressively add:
- Lakeflow / streaming
- Unity Catalog
- AI Search / Vector Search
- MLflow
- Agents
- MCP
- Multi-agent orchestration
- CI/CD

## Repository structure

- `databricks.yml` - Databricks Asset Bundle configuration
- `resources/` - Databricks resources
- `src/` - Python source code
- `notebooks/` - exploratory notebooks
- `sql/` - SQL setup scripts
- `tests/` - unit tests
- `agents/` - future agent implementations
- `mcp/` - future MCP server
- `app/` - future application
